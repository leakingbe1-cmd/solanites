# Archive

Superseded promotional assets, kept for reference only. **Never use anything listed here for new posts.**

Nothing is physically stored here yet. The only superseded creatives found are the first `phoenix-intro` promo renders (three videos, a poster, three end-card layers and a starter-pack draft). They show the private website URL, so they were deliberately **not** copied into this library: a copy would repeat the URL in a new place. They remain on the `phoenix-intro` branch and are listed under "Do not publish" in [`../MANIFEST.md`](../MANIFEST.md), each with its prelaunch-safe replacement.

When a library asset is replaced in future, move the old file here under the same relative path (for example `archive/posters/<file>`) and set its status in `MANIFEST.md` to "archived".
