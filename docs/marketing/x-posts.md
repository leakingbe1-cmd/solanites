# Solanites: X starter pack

Ten posts built only from features that exist in the code today. Pair them with the
phoenix creatives (`art/promo/`, built by `scripts/promo-assets.sh`).

**Before posting, check the bracketed notes.** Real egg tracking only works once the token
mint, Solana data provider, database and scheduler are configured in production. Until then,
posts that promise eggs from real holdings would not be true yet. The holder distribution is
planned, not built, and its terms are unpublished: never quote amounts, percentages or dates for it.

Site: https://solanites.vercel.app
